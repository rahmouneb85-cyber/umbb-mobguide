## 📋 Overview
Bilingual mobile application (French/Arabic) designed to help students 
navigate the University of Boumerdes (UMBB). Covers all faculties, 
departments, and academic programs.

## 📊 Coverage
| Feature | Details |
|---------|---------|
| Faculties | **8 faculties** |
| Departments | **25+ departments** |
| Languages | **French & Arabic** |
| Platform | **Android** |

## 🛠️ Tech Stack
- **Language:** Java
- **IDE:** Android Studio
- **UI:** XML layouts (bilingual RTL/LTR)
- **Data:** Static DataProvider

## 🎯 Features
- ✅ Full bilingual support (French/Arabic)
- ✅ Browse all 8 UMBB faculties
- ✅ Explore 25+ departments
- ✅ Department detail pages
- ✅ RTL Arabic interface support
- ✅ Offline — no internet required
